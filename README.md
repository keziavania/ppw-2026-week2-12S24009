## Fitur dan Spesifikasi Teknis
1. **Arsitektur Semantik Dokumen:** `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, dan `<footer>`.
2. **Data Terstruktur:** Tabel semantik lengkap (`<caption>`, `<thead>`, `<tbody>`, `<tfoot>`, `scope`) dan HTML Lists (`<ul>`, `<ol>`).
3. **Formulir Accessible (WCAG 2.2 AA):** 6+ kontrol input (`text`, `email`, `tel`, `number`, `radio`, `checkbox`, `select`, `textarea`), terbagi dalam dua `<fieldset>` dengan pasangan `<label for="...">` eksplisit.
4. **Desain CSS Modern:** Menerapkan Universal Reset, palet warna 60-30-10, CSS Grid & Flexbox, serta responsif via Media Queries.
5. **Deployment:** Live di GitHub Pages.
